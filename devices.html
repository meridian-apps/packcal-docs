Supported devices

87 Garmin watches

PackCal runs on Garmin watches with Connect IQ 3.2 or later, across AMOLED and 64-color MIP (memory-in-pixel) displays. The list below is grouped by product family.

The list grew a lot in v1.0.5 (August 2026). That release added the older Connect IQ 3.x generation — fēnix 6, Instinct 2, Enduro, Venu Sq, vívoactive 3 and 4, and the Forerunner 55/245/645/745/945 — along with the Approach, D2, Descent and MARQ families. If you checked on an older watch before then and were told no, it is worth checking again.

The Connect IQ Store listing has the live compatibility check, install only completes on a supported device.

One field, every screen size

A data field's cell can be anything from a full single-field screen on a Forerunner 965 down to a quarter of the screen on a four-field Instinct. PackCal draws by hand for the cell it's given: on a spacious single-field screen it shows the calorie hero plus a live rail, the pack-bonus pill, and a footer; in a denser multi-field layout it degrades to a labelled number, then to a bare number when the cell is tiny. The layout is also display-shape-aware (round and rectangular watches each get a layout tuned to their bezel), with a condensed, sun-legible numeral face.

Watches with less memory show the simpler view. On the more memory-limited watches — the fēnix 6, Instinct 2 and Crossover, Enduro, Venu Sq, vívoactive 3 and 4, and the Forerunner 55/245 — a full single-field screen shows the labelled number rather than the calorie hero with the live rail and pack-bonus pill around it. The calorie math is identical on every watch. Only what is displayed alongside it differs.

Connect IQ version

PackCal builds against Connect IQ API 3.2, which is what lets it reach watches as old as the fēnix 6, Instinct 2 and Enduro. Newer watches use newer Connect IQ features where they exist, and older ones fall back automatically. You don't need to pick, the right path runs on the right device.
